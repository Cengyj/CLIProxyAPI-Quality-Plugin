## 代理设置

登录代理独立于 CPA 业务请求的代理配置。它同时用于宿主启动的密码与 TOTP 登录和后续授权码兑换。选择顺序为：

1. 本次临时登录或账号指定代理。
2. 登录设置中的默认代理。
3. 重授权目标凭证原有代理。
4. CPA 全局代理。

留空表示沿用下一层设置；`direct` 表示明确直连。配置在任务创建时确定，不会因任务执行期间修改设置而中途切换出口。已打开的官方浏览器授权窗口使用操作者浏览器自己的网络设置，宿主代理不能替它配置浏览器。

账号代理、默认登录代理以明文保存在宿主已有账号数据库中，不需要加密密钥。批量导入可为本批账号设置代理，账号资料可单独覆盖；临时登录可指定本次代理。代理设置不会改变已经绑定的 CPA 凭证的业务代理，不会自动发起登录或模型请求。

支持 HTTP、HTTPS 和无需用户名密码的 SOCKS5/SOCKS5H。Chromium 的 SOCKS5 不支持代理用户名密码；此组合会被明确拒绝，请改用支持认证的 HTTP/HTTPS 代理。SOCKS5H 在浏览器端映射为 SOCKS5 的远端 DNS 行为。
