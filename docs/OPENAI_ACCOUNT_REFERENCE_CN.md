## 日志与持久化

新增鉴权接口 `GET /v8/management/credential-logins/logs?id=任务ID`，只允许 GET 并返回 no-store。响应为 `job_id`、`entries`、`legacy`。每个事件包含递增 ID、实际 UTC 时间、级别、任务状态、服务阶段及允许列表中的错误代码/步骤/原因。

日志和对应任务状态在原有本机 `credential-login.db` 的同一 Bolt 事务保存；状态、阶段或安全诊断变化时追加，重复保存不追加；每个任务保留最近 200 条，截断后事件 ID 继续递增。字段以明文保存，没有加密或数据迁移脚本。旧记录保持可读，但缺失的旧步骤不会补造；旧任务在真实后续状态变化时仍可产生新记录。

这是宿主实际服务阶段与结果日志，不是浏览器每次点击或网络响应的原始日志。不会存储密码、TOTP、OAuth URL、token 或原始上游输出。

界面提供“本次／历史记录”“全部／异常”、刷新、复制当前筛选结果、原始安全事件展开和跟随最新。日志区域最高 270px，独立滚动；手动滚动或展开原始记录暂停跟随。刷新保留阅读位置、展开项与键盘焦点；失败保留已经读取的内容并支持重试；切换账号与断开连接后丢弃过期请求。

历史记录仅从最近 200 条全局任务中关联当前账号的真实记录，按 account_id 关联，last_job_id 兜底，不按邮箱混合其他账号历史。未提供完整历史分页，因此明确说明查询范围。
