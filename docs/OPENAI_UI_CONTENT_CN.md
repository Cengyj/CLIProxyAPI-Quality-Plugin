# OpenAI 登录内容重排：UI 8.0.0

本轮将插件更新为 0.6.1、UI 更新为 8.0.0。重构范围为 OpenAI 登录页的内容组织、排版与局部导航，保留现有 CPA 三主题和业务流程。

## 内容结构

| 入口 | 布局与操作 |
| --- | --- |
| 账号管理 | 全宽账号目录，搜索、状态筛选、分页和巡检/导入操作集中在列表上方 |
| 导入账号 | 独立宽表单，左侧批量资料，右侧格式说明；返回保留目录筛选 |
| 账号资料 | 左侧备注和自动授权许可，右侧完整邮箱、密码与 2FA；明确启用后才修改登录资料 |
| 临时登录 | 左侧授权方式和目标，右侧输入账号资料；提交操作在底部 |
| 登录任务 | 约 300px 的任务列表搭配宽详情区；候选身份与确认动作在同一面板 |
| 巡检设置 | 独立第四个子页，集中设置巡检间隔、巡检开关与全局自动授权开关 |

移除常驻侧栏，导入、编辑和选择授权目标时用整个工作区完成操作。关闭或返回后清空读取的秘密资料；目录搜索与筛选保留。巡检设置草稿在局部视图切换后保留，只有点击保存才写入。

桌面表单保留可见操作页脚，手机使用正常文档滚动，字段按阅读顺序排列。所有邮箱、密码、2FA 长期密钥与身份 ID 继续完整展示。静态资源不包含新增图片、外部字体或远端依赖。

## 验证范围

使用离线假账号和本机模拟服务，覆盖三主题及 1280×720、1440×900、768、390、360 像素宽度。检查目录、导入、编辑、临时登录、巡检设置、任务和候选确认，以及异步请求、秘密清除、设置草稿、搜索筛选和任务滚动。

证据目录为 `artifacts/login-content-8.0.0/`。测试报告只证明所记录的离线和本机行为；本轮没有使用真实 OpenAI 账号或调用模型。
