# UI 9.4.0 重构说明与功能验收

日期：2026-11-17（Asia/Shanghai）。状态：**历史版本；UI 9.4.0 已完成原生构建并部署，现由 UI 10.0.0 替代**。当前版本见 [UI 10.0.0 重构及部署说明](UI_REWORK_10_0_0_CN.md)。

本轮用户要求重新梳理现有功能，对 UI 进行重构、排版和美化，并选择“贴合 CPA：简洁专业、紧凑高效”。本文保留 UI 9.4.0 阶段的功能地图、呈现约束和验收依据。该阶段先完成源码与离线预览，随后已将 UI 编入原生插件并更新 8317 实例；后端版本保持 0.16.0。

当前产品建立在官方 CPA 8.0.76 的公开原生插件接口上。插件源码版本为 0.16.0，内嵌 Go/Sobek 引擎为 2.1.1，本轮开始时 UI 为 9.3.0。保留官方宿主不变、使用鉴权 v0 插件通道和质量观察的决定继续有效。旧文档中的补丁宿主、v8 自定义业务路由、独立质量暂停与释放属于历史方案，不能作为本轮恢复这些能力的依据。

## 一、代码职责与页面入口

前端仍为原生 HTML、CSS、JavaScript ES Modules，通过 Go embed 内嵌。三个工作区名称统一为 **智商测试 / 质量观察 / 账号管理**；内部路由值 `manual`、`operations`、`login` 保留，以兼容现有链接、状态与处理器。

| 文件 | 职责 | 维护约束 |
| --- | --- | --- |
| `plugin/ui/index.html` | 页面外壳、表单、三个工作区、原生弹窗与静态空态 | 保留现有控件 ID、表单关系和事件挂接点；图标必须配合可读标签 |
| `plugin/ui/style.css` | 三主题、组件、密度、响应式、内嵌与独立布局 | 通过共享角色与组件规则组织，不按单个截图叠加相互覆盖的尺寸补丁 |
| `plugin/ui/app.js` | 管理连接、页面导航、模型测试、历史、规则、指标、主题适配 | 呈现改动不能触发额外模型请求或改变凭证/规则动作语义 |
| `plugin/ui/view.js` | 结果、样本证据、规则、凭证限制、历史归属的渲染与安全预览 | 持续转义不可信内容；执行完成、质量正确、凭证可用分开表达 |
| `plugin/ui/login.js` | 账号目录、任务、巡检、资料/导入/安全弹窗、行内日志及读取状态 | 保留轮询、版本、未决动作、敏感草稿清理和防重复提交逻辑 |
| `plugin/ui/client.js` | 鉴权请求、会话代次、读取消、登录路由及幂等键校验 | 不为视觉改动改变网络策略或增加写入重试 |
| `plugin/ui/embed.go` | 六份前端资源的嵌入 | 浏览器预览不等于动态库已重建或已部署 |

静态页面位于 `/v0/resource/plugins/model-quality/index.html`；数据与业务动作使用 `/v0/management/plugins/model-quality/`，账号动作在其 `/login/` 子路径。静态资源公开可读不代表已经获得管理权限。

## 二、现有功能地图

### 1. 公共外壳与管理连接

- 主导航在三个工作区之间切换，保留各自的当前局部视图；不能用新导航替代或遗漏既有功能。
- 顶部展示插件自己的连接状态、数据更新时间/陈旧状态、刷新和主题入口。CPA 父页面已登录不等于插件已连接。
- 连接弹窗接收管理密钥。成功后在插件自己的端点作用域 localStorage 项中明文保存，刷新时尝试重连；主动断开或当前会话 401 清除保存的密钥及受保护页面数据。
- 暂时网络故障保留已成功读取的内容，并区分未连接、未读取、正在读取、已读空集合和读取失败。陈旧内容不能继续作为敏感写入的可信快照。
- 刷新、主题变化、导航、打开页面、编辑/保存题目不产生模型调用。

### 2. 智商测试

主任务是“选择凭证和题目 → 编辑题面 → 选择单个模型、思考强度与回答份数 → 明确开始 → 同页阅读与比较”。

| 页面分区 | 现有功能与交互 |
| --- | --- |
| 测试配置 | 从 CPA 可见凭证列表选择目标，查看限制和可用状态；模型列表随目标变化；不能手工冒充不存在的凭证或绕过限制 |
| 题目内容 | 手动页面提供内置逻辑题、HTML/SVG 题和自定义题；可编辑题面，修改内置题面后按自定义题处理，不继续沿用原题答案绑定。随机题保留在规则配置中 |
| 执行选项 | 单模型、由能力决定的思考强度、1–8 份独立回答；未知推理能力保持未知；当前手动页没有温度、输出上限、对照或 judge 配置表单 |
| 本次回答 | 展示执行进度、完成份数、总耗时、可用的 TTFT/token；每份回答独立呈现；手动模式不自动评分，也不展示通用 IQ 分数 |
| 任务操作 | 活动任务停止、同配置再测试、下载结果；这些均由用户明确操作触发；历史冻结配置与当前可编辑草稿分开 |
| 阅读与预览 | 复制原文、展开完整回答、HTML/SVG 隔离预览、测试详情；“展开阅读”收起配置但保留草稿，可返回配置 |
| 测试记录 | 分页查看持久化任务，选择记录展示冻结条件与样本；历史多模型记录保留查看/对比能力，不向新建手动测试重新加入多模型配置 |

短回答按内容自然展示，长回答应有明确的局部滚动或展开方式。复制与下载必须获得完整原文，不能复制截断的视觉片段。

### 3. 质量观察

官方模式为 `official_observation`。规则、结果、指标与历史仍然可见，但官方公开接口未提供独立质量暂停/释放和可信最终证据；界面不能暗示安装此插件即可自动停用低质量凭证。

| 局部视图 | 分区和交互 |
| --- | --- |
| 需要关注 | 质量与覆盖指标、已知/未知用量、统计口径、CPA 凭证限制、保留的历史暂停归属 |
| 检测规则 | 规则目标、模型/题目、启用与调度状态、连续失败证据、查看运行结果、新建/编辑、显式执行、暂停/恢复检测和删除 |
| 审计记录 | 持久化操作记录、近期规则运行，按实际记录跳转查看关联任务，不虚构缺失证据 |
| 规则编辑 | 五组信息：目标与题目、判定条件、检测调度、凭证处置、调用预算与保留；保留确定性/人工/独立模型判题配置、随机题对照、固定间隔/Cron/时区与资源参数 |
| 全局开关与预算 | 全局调度许可、并发/队列、调用/token、模型/样本/响应、存储与保留限制；保存不执行模型 |

“暂停检测规则”只停止规则后续执行，不改变 CPA 凭证状态。定时观察必须同时满足全局和规则调度许可。官方宿主下处置只能观察，自动暂停禁用，解除动作不可用；历史归属必须保留且明确标为待核对，不能因视觉简化而隐藏剩余限制或伪装已释放。

### 4. 账号管理：账号目录

账号管理保留三个局部视图：**账号 / 登录任务 / 代理与巡检**。账号目录是默认视图。

- 顶部入口包含导入账号、巡检和代理设置。全部、待处理、已绑定、进行中显示真实计数；进行中筛选当前活动账号，不自动跳到任务列表。
- 搜索覆盖邮箱、备注和 CPA 凭证标识；保留每页 20 条分页、清除筛选、已加载空目录与无匹配结果的区别。
- 六列信息为账号、CPA 状态、当前操作、操作时间、操作类型、操作。完整邮箱、备注、绑定身份与诊断信息保持可读，不以截断取代识别对象所需的信息。
- CPA 健康状态与最近一次登录/安全操作结果分开。历史授权成功不能把当前未知健康状态染为成功；“已绑定”也不表示模型调用已验证。
- 行操作保留 2FA 登录、资料、日志、任务、巡检和更多。更多包含重置 2FA、退出所有设备和删除账号。
- 行内 2FA 登录成功后自动保存并启用 CPA 凭证，进度留在账号行；不增加候选确认、不自动切页、不因重绘重复发起登录。

### 5. 账号资料、导入与安全弹窗

| 弹窗 | 功能与呈现要求 |
| --- | --- |
| 批量导入 | 每行 `邮箱----密码----2FA`，1–100 个账号；行数、原始错误行号、重复/已有账号和 TOTP 长期密钥校验；密码中的空格与分隔符保留；可给本批账号指定代理；导入只保存资料 |
| 账号资料 | 查看完整邮箱/密码/长期密钥、复制资料及复制反馈；显式勾选后更新密码与2FA；备注、账号代理、单账号自动登录许可；查看已保存配置的实际出口及来源；可明确选择已有凭证登录目标 |
| 删除账号 | 需要明确确认；删除插件中的账号资料并停止其巡检，CPA 凭证保留 |
| 重置2FA | 显式手动确认；可选退出所有设备和完成后重新授权；按选项展示实际步骤；先确认并保存新密钥，再进入后续步骤 |
| 退出所有设备 | 可独立执行，也可显式选择后续重新授权并启用CPA；不能把重新授权作为默认必定发生的事实 |
| 安全操作核对 | 展示已经确认的阶段和未决结果；仅有确证时出现“完成本地保存”；该操作不能再次执行远端重置、退出设备或OAuth |

弹窗继续使用原生 `dialog`：可读标题、初始焦点、键盘隔离、Esc/取消关闭、返回原入口。提交进行中防止关闭或重复提交；显式关闭和切页按现有规则清理敏感草稿。详情读取失败不能露出上一次账号资料，迟到响应不能重新填入已关闭弹窗。

### 6. 登录任务与行内日志

- 任务列表与详情并列显示，保留选中项、手动滚动位置、活动阶段、结果和安全诊断；手机按阅读顺序排列。
- 登录阶段包括排队、会话、密码、2FA、网站校验、OAuth兑换、核验、保存和取消等；用实际状态说明正在发生的步骤，不把“已受理”显示为“已成功”。
- 对新账号登录的自动提交展示保存/启用结果；历史待提交候选仍保留明确核对、提交与丢弃入口，不因刷新自动重放。
- 历史人工 OAuth 任务保留安全授权链接和回调提交；这是历史任务兼容，不是新增浏览器自动登录或失败自动回退。
- 安全结果分别显示新2FA已保存、设备已退出、后续授权未完成、结果未知等。后续失败不能覆盖此前已经完成的动作。
- 行内日志紧接选中账号，跨六列展示；同一时间只展开一个账号；支持异常筛选、当前任务/账号历史、原始安全字段披露、复制和读取重试。
- 账号历史按账号 ID 单独读取，不受全局最近200条任务遮挡，也不把同邮箱但不同账号所有权的记录混入。
- 下载报告只包含允许导出的身份、状态和固定诊断元数据，不包含密码、2FA种子、令牌、管理密钥或OAuth回调。

### 7. 代理与巡检

- 代理优先级为账号指定 → 默认登录代理 → CPA 凭证代理 → 直接连接；`direct` 明确选择直连，留空表示继承。
- 支持 HTTP、HTTPS、SOCKS5、SOCKS5H 以及代理认证。SOCKS5 本地解析域名，SOCKS5H 由代理解析；Docker 中 `127.0.0.1` 是容器自身。
- 代理设置只在明确保存后对新登录生效；保存不探测、不登录，不更改 CPA 业务代理。
- 巡检间隔为5–1440分钟，默认15分钟；巡检读取 CPA 已记录的认证状态，不调用模型。
- 自动巡检、全局自动登录和单账号自动登录是独立许可，默认关闭。后台修复还要求明确认证失效证据，且继续遵守人工禁用、身份、策略、历史暂停及未决结果保护。
- 轮询不覆盖尚未保存的设置草稿；版本冲突不能通过静默覆盖处理。

## 三、本轮排版与视觉方向

### 信息层级

1. 主导航负责切换任务；工作区标题负责说明当前位置和用途；局部导航负责当前任务内的视图，避免三者使用相同的视觉强度。
2. 页面以主要工作面组织：测试配置与回答、观察指标与规则、账号目录与详情。保持紧凑，减少重复说明和空白卡片。
3. 账号、凭证、模型和主要结果优先；时间、版本、执行条件和能力解释作为可读的次级信息，不缩成难读脚注。
4. 危险动作使用明确文字与独立确认；主要提交、次要动作和只读查看采用稳定的按钮层级。图标用于帮助扫描，不能取代状态和动作名称。
5. 空态、加载、失败、陈旧、进行中、部分完成和结果未知分别呈现。减少技术措辞时必须保留真实含义。

### 组件与主题

- 延续 CPA 的中性色、轻边框、紧凑下划线导航、统一按钮/字段/开关、低装饰卡片与清晰表格，不引入新的前端框架、外部字体或 CDN。
- 浅色、纯白和深色保持独立的背景/卡片/输入/浮层/悬停角色；状态色需要同时检查底色、文字和边界的可读性。
- 执行完成采用中性状态。只有明确的质量正确、规则启用或健康状态才按各自语义使用正向色，不能用一套绿色标签代替所有成功含义。
- 单号、时间、样本数和用量适合等宽数字；长邮箱、模型和凭证标识应允许换行或在对应局部区域滚动。
- 保留键盘焦点、原生标签、状态播报、跳转主内容入口和减少动态效果设置；轮询不引入反复入场动画。

### 桌面、手机与内嵌

- 桌面优先保证配置、主要操作和当前结果的连续性；账号长列表使用明确的局部滚动与分页，不为单行数据制造大块空白。
- 手机按任务顺序堆叠；宽表只能在局部滚动，不能把整个文档撑宽；账号对象、状态和操作保持对应关系。
- 窄屏输入与主要触摸目标保持可用尺寸；弹窗标题、正文与底部动作需要在短视口下仍然可达。
- 同源可识别 CPA 内嵌时只读跟随父页已应用的 `data-theme`，不读取父页认证状态、管理密钥或 localStorage，也不修改父页DOM。
- 独立打开或无法识别宿主时保留自己的身份、连接和主题选择。内嵌不再绘制另一套 CPA 全局侧栏；宿主浮动工具避让需由实际视口验证，不能假设固定截图尺寸适用所有环境。

## 四、必须保留的业务与安全边界

| 边界 | 本轮不能改变的行为 |
| --- | --- |
| 官方宿主 | 不改CPA源码；不导入宿主internal；业务通过官方鉴权插件通道 |
| 模型调用 | 打开页面、导航、刷新、保存配置或查看历史不调用模型；只有已授权的明确执行或已启用调度可以创建任务 |
| 凭证限制 | 人工禁用、质量暂停归属、原生冷却及其他限制分开；质量暂停凭证不能用于测试、对照或judge |
| 质量结论 | HTTP成功不等于回答正确；基础设施错误、未知、截断、拒答或判题失败不推进质量失败判定 |
| 官方能力缺口 | 独立暂停/释放、自动暂停和可信最终证据不可用；不以人工禁用模拟质量暂停，不静默清理历史归属 |
| 单步账号登录 | 用户新发起的账号行2FA登录授权成功后保存并启用；不追加重复候选确认，也不将其推广到历史待确认任务 |
| 自动修复 | 全局和账号许可共同约束；不重新启用过程中被人工禁用的凭证；保存前复查身份与策略 |
| 保存不确定性 | 官方save没有原子CAS；`commit_unknown`、`saved_not_adopted`和身份冲突仍阻止盲目重试，不把界面刷新当作事务成功 |
| 安全操作 | 重置/退出仅由明确手动动作触发；未知远端结果隔离；先保存已确认的新种子，重启、巡检和本地完成不重放远端修改 |
| 写入请求 | 保留幂等键、进行中锁和版本检查；不增加自动写重试或固定写入超时 |
| 读取恢复 | GET期限、结构校验、会话代次和迟到响应保护保留；读取失败保留有效内容并禁用依赖失效快照的写入 |
| 敏感信息 | 按既有要求在受鉴权资料中显示完整值；账号材料不新增浏览器持久化；关闭/断开/401及时清理，不泄漏至日志、URL或导出 |
| 模型HTML | 原文转义；预览通过严格CSP与sandbox隔离，禁止脚本、外部网络、表单、导航及父页访问 |
