# 账号资料表单重构

版本：插件 0.29.1 / UI 13.6.1 / Runtime 2.2.1。

## 排版

将左右两个独立分栏改为连续表单，去掉“更新密码与 2FA”开关和“开启后编辑，点击保存账号生效”说明。

- 登录信息：第一行邮箱与备注，第二行密码与 2FA 长期密钥；复制资料位于分区标题右侧。
- 连接与授权：代理占整行，实际已保存出口在输入框下方；自动登录许可和 CPA 绑定以轻分割线分隔。
- 沿用插件配色，缩小弹窗宽度并收紧字号和间距。手机字段纵向排列，标题与底部删除、关闭、保存操作固定。
- 历史记录、全局设置及账号列表沿用 UI 13.6.0。

## 编辑与提交

邮箱继续只读。密码和 2FA 可直接编辑，只有点击“保存账号”才提交。前端将当前输入与读取时的临时值比较；只改备注、代理或自动登录时不附带 credentials，密码或密钥编辑后还原也不会重复更新。

实际修改登录资料时，密码与密钥不能为空，2FA 沿用导入时的 Base32 / TOTP URI 校验。仅修改其中一项时，另一个原值随请求完整保留。后端继续验证账号身份、资料格式和版本号。

对照值只存在当前表单内存中，关闭、页面切换、断开和提交时清空。未保存的资料修改不会跨账号保留。保存失败后仍要求重新读取核对，不自动重试。安全待核对账号保持编辑、复制和删除禁用，待核对资料仍可查看。

复制资料复制当前表单中的邮箱、密码和长期密钥；不隐式保存或发起登录。

## 验证

使用内存合成服务验证普通配置不提交 credentials、修改后还原、密码单独修改、密钥单独修改、空值 / 六位验证码拦截、关闭丢弃、账号切换清理、读取失败与保存失败，以及安全待核对禁用。

账号资料覆盖三主题、五屏宽和短屏共 16 项布局，完整工作区继续通过既有布局检查。构建运行 Go 检查；隔离 CPA 验证插件加载与重启。CPA 内嵌页面的候选与安装后检查均使用合成业务数据，不操作真实账号。
