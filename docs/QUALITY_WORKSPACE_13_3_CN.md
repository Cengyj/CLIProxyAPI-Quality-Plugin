# 质量运维双栏排版优化

版本：插件 0.28.2 / UI 13.3.0 / Go＋Sobek 2.2.1。

## 问题与参考

此前 `.quality-workspace` 使用 `align-items: start`，左右列表分别设置 670px、620px 最大高度。规则少、记录多或记录为空时，两张卡片独立撑高，底部和分页位置不能对齐。

本轮参考用户截图及已保存的 sub2api `production@feb761541918d25a73779c6ea42ee28f61b5591e` 源码。其质量运维使用统一高度的双栏容器、纵向 flex 面板、独立滚动列表和固定底栏。参考文件位于 `artifacts/quality-workspace-0.27.0/reference/AccountQualityView.vue`；本轮未宣称该快照是上游最新版本。

## 排版与交互

- 桌面采用较窄的规则栏和较宽的记录栏，共享一个高度；依据当前插件视口和内容顶部位置计算可用空间，最小 460px。滚动页面不会改变面板高度。
- 两栏标题区统一高度。列表内部滚动，规则统计和记录分页留在底部，左右下边缘与底栏分割线对齐。记录表头在列表内固定。
- 左栏增加“全部规则”入口，点击即可清除规则、批次筛选；底部展示规则数量和定时规则数量。保留原有搜索、状态筛选及卡片操作。
- 规则卡片采用较轻字重、紧凑模型标签和统一操作间距；选中态沿用主题强调色。
- 运行记录按检测时间、凭证 / 规则、检测结果、凭证处理和详情分列。模型与请求强度紧凑排列，检测结论与实际处置分别读取原有字段；没有记录的处置显示“未记录处理结果”，不推断成功。
- 移除运行记录标题右侧过时的“仅观察”标记，改为当前筛选范围的记录总数。
- 容器宽度不超过 1000px 时，上下排列；较窄屏幕将记录行改为带标签的卡片，保留分页和键盘滚动。
- 配色继续使用现有浅色、纯白、深色主题。新建 / 编辑规则弹窗、后台接口、检测策略、历史记录及之前移除的底部区域不变。

## 验证

- 现有工作区回归：111 个布局检查、44 张截图，无未捕获页面错误。
- 双栏专项：空列表、无记录及 6 种宽度 × 3 种主题，共 20 个场景；验证面板、标题和底栏对齐，以及窄屏堆叠。
- 20 条记录下验证固定表头、列表滚动及分页位置；验证全部规则入口、规则筛选、错误保留、分页和弹窗交互。
- 真实 CPA 管理壳验证候选及安装后资源，插件业务请求转向合成数据，禁止写入。
- 插件 Go 测试、vet、原生共享库构建；隔离容器加载、重启及凭证策略假上游验证。

源码基线、补丁、截图、安装包与部署核对结果位于 `artifacts/quality-layout-0.28.2/`。部署保留原 CPA 镜像、配置、凭证和插件业务数据，不执行真实账号操作或模型调用。
