# 质量运维工作台重构：UI 13.0.0

对应插件 0.27.0，官方 CPA 8.0.76 保持不变。此前 UI 12.18.0 的概览、规则、运行与审计三个标签页已合并；新建和编辑规则改为原生模态弹窗。

## 参考与布局选择

本轮核对 sub2api `production@feb761541918d25a73779c6ea42ee28f61b5591e`（提交时间 2026-11-18），主要阅读 `frontend/src/views/admin/AccountQualityView.vue`、质量模型快捷项、账号选择组件与质量运维文档。源码快照与提交记录位于 `artifacts/quality-workspace-0.27.0/reference/`。

参考页把概况、规则和运行记录放在同一工作区，规则编辑在独立浮层中进行。本插件采用这一信息结构，并按 CPA 的凭证、规则、范围批次和样本数据适配；没有引入上游分组处置、恢复、批量修改或模板分发。

- 顶部显示已保留样本的通过率、覆盖率、未知结论与已知用量。选择单条规则不会改变全局统计口径。
- 桌面左侧是规则卡片列表，提供名称／模型／凭证搜索与运行状态筛选；右侧显示运行记录。窄屏依次纵向排列，无质量页内标签切换。
- 点击规则名称，在右侧读取该规则的历史；「最近批次」只查看对应范围批次，可退出批次或清除筛选。全部历史和规则历史均可分页，每页 20 次运行。
- 运行状态与质量判定分别展示。正确、答错、未知取自实际保存的样本判定；完成请求不等于质量通过。无样本显示「暂无判定」，裁剪的样本显示裁剪数量，请求强度来自当轮冻结配置。
- 凭证状态、历史暂停归属、最近 20 条审计与统计口径在同页下方展开。存在历史暂停归属时，折叠标题显示「待核对」。

## 规则弹窗

弹窗保持连续表单：名称 → 范围 → 多模型／思考强度／采样 → 判题 → 运行计划。标题与底部操作固定，内容区域单独滚动。

名称改为明确的标签与常规输入框，移除大号可编辑标题。模型区域使用插件主题变量，浅色与纯白模式不再出现深色模型栏。检测范围使用原生单选控件与紧凑分段背景，快捷模型、模型目录和手动录入继续保留。

只有一个「启用定时检测」开关，默认关闭；底部不再显示重复的定时说明。必要的历史计划、暂停归属与不可执行原因继续显示；开关仍保留可访问的文字描述。Cron 仍使用「检测周期（五段 Cron，服务端时区）」完整标签和 `*/30 * * * *` 默认值。

保留多模型、默认高强度与五档 `low / medium / high / xhigh / max`、每模型样本数、题面与参考答案、旧周期和旧档位兼容、结果保留、逐字段校验、保存期间防重复提交，以及未保存更改保护。Escape、关闭按钮和取消均走同一草稿保护流程，关闭后返回发起按钮。

## 实现与边界

`GET /v0/management/plugins/model-quality/runs` 增加可选 `rule_id`，与 `source`、`scope_batch_id` 共同过滤后再排序分页。不存在的规则 ID 返回空列表；规则删除后仍可读取其保留历史，不要求规则实体存在。没有增加写入权限或新的执行入口。

读取失败时保留原有列表并显示过期提示，停止翻页直到读取恢复；切换筛选时清除旧范围内容，过期异步响应不能覆盖新选择。所有检测仍遵守 CPA 的禁用、冷却与暂停归属限制，官方宿主不支持的独立质量暂停和释放仍不可用。
