# 智商测试排版与底部对齐

版本：插件 0.28.3 / UI 13.4.0 / Go＋Sobek 2.2.1。

## 调整内容

原来的设置区和回答区按内容分别撑高；多份回答长度不同时，卡片下边缘及操作区也不齐。本轮将智商测试改为统一高度的工作区，桌面设置栏宽度为 300–350px，回答区使用剩余空间。依据插件视口与顶部内容计算高度，调整主题、窗口、展开阅读或切换页面时重新计算。

- 两栏统一标题高度和底栏分割线。开始测试移动到底部，右栏按当前视图显示结果操作或历史分页，正文内部滚动。
- 设置区分为模型配置与题目内容，收紧字段字号、字重和间距；题目编辑框填充可用空间。短屏可滚动表单，按钮留在底栏。
- 同一行的回答采用等高卡片，底部信息与操作区对齐；正文保持可滚动、展开、复制及下载能力。
- 空态图形缩小，标题与说明使用轻量字号，保留插件现有浅色、纯白、深色主题。
- 窄屏继续使用设置／回答／记录切换，复用原表单以保留草稿。最小工作区高度降为 380px，减少操作栏超出首屏；极短窗口仍允许页面滚动。

测试参数、请求、准入限制、执行策略与账号操作保持原有行为。本轮仅改变布局、呈现和前端进度摘要，不触发真实测试。

## 验证与交付

工作区回归覆盖空态、历史、长短回答、展开阅读、短屏滚动、三套主题、六种屏宽及内嵌环境；自动检查面板上下边缘、标题分割线、底栏、回答卡片及横向溢出。历史翻页等待实际页码更新后再断言，避免将网络等待误报为页面错误。

在真实 CPA 管理壳中分别验证候选包与已安装资源，插件业务请求使用内存合成数据并禁止写入。构建与原生加载、重启、凭证策略验证使用隔离容器及假上游。

源码基线、差异、截图、验证报告与安装包位于 `artifacts/manual-layout-0.28.3/`。部署核对 CPA 镜像、配置、凭证文件和插件业务数据；完整结果以该目录报告为准。
