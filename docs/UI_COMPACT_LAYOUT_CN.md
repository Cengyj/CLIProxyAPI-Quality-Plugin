# UI 4.5.0 同页配置与回答

日期：2026-11-15（Asia/Shanghai）。插件后端版本仍为 0.3.1。用户指出 4.4.0 的题面和右侧选项占用过高，使回答被挤进独立标签页；4.5.0 据此恢复“上方配置、下方回答”的连续任务。主要验收场景仍为 CPA 1280×720 桌面窗口及其实际 iframe 宽度。

## 当前内容与排版

- 配置默认一直可见。回答区域仅保留“本次回答 / 测试记录”局部导航；提交或切换记录不会自动收起配置。
- 桌面题面框高度为 104px，长题面在框内滚动；右侧选项区域为 156px，输出设置展开后在列内滚动。手机题面框为 160px，按任务顺序自然排列。
- 凭证与题目使用桌面同行标签，模型、思考强度与回答数量保持清晰字段。开始按钮与准入说明位于选项滚动区域外，不靠缩小关键文字取得空间。
- 回答区使用剩余桌面高度。运行摘要与冻结条件入口共用紧凑行，短回答保留自然高度；“展开阅读”由用户显式收起配置，“返回配置”恢复同一份草稿。
- CPA 颜色、组件、卡片和导航语言继续沿用。质量运维的并列关注区域、局部表格与长表单布局保持不变。

手动测试仍为单模型、1–8 份独立回答，不自动评分、不暂停凭证。鉴权、调度、暂停归属、人工解除和隔离预览边界未改变。长题面、回答和历史不承诺全部无滚动；目标是桌面配置、主操作和回答开头同时可见。手机、200% 缩放和矮窗口允许自然页面滚动。

## 当前验证记录

本次证据目录为 `artifacts/samepage-4.5.0/verification/`，基线使用修改前冻结的 4.4.0 源码和资源。九份最终命令记录均通过并绑定当前输入：静态 UI 构建、题目纯逻辑回归、插件独立 module 测试、原生动态库构建与生命周期，以及原生 API、原生浏览器、独立 UI 和实际宿主外壳验证。源码、静态输出和动态库实际返回资源经哈希核对一致。

浏览器报告包含独立 UI 58 项检查 / 88 张截图、实际宿主外壳 15 项检查 / 69 张截图、原生浏览器 13 项检查 / 4 张截图；原生题目 API 通过 8 项检查。同页提交、显式展开阅读及返回、草稿和轮询状态保留，以及原有暂停、解除、取消和安全预览断言均按当前入口执行。所有模型流程使用隔离 fake upstream 与假凭证。

实际 CPA 1280×720 窗口在侧栏展开时提供 1064×720 iframe，文档高度为 720。题面框为 104px，选项区域最大 156px；开始按钮位于 y=391.55–435.55，配置下方可完整看到至少一份 46.8px 高的短回答正文。三主题、侧栏展开/折叠下，18 组桌面同屏断言及 27 组宿主几何检查通过。长内容、手机、平板、实际 200% 浏览器缩放和必要的自然回流分别留有截图。相同假数据的 1280×720 前后对照见 `artifacts/samepage-4.5.0/comparison-1280x720.png`，对应来源、截图及数据哈希保存在同目录的 `comparison-provenance.json`。

布局 detector 的五项现有提示记录在 `verification/layout-detector.json`：两个表格 wrapper 的文字内距由单元格承担，两个原生 dialog 底部内距采用 safe-area/max 表达式并有实际测量，一项规则处置范围提示保留必要业务说明。机械检查不替代视觉判断，也不构成无障碍认证。

本次仅修改 UI，未重复宿主全量 Go 测试及此前插件 race/vet 检查。实体手机触摸、屏幕阅读器、其他浏览器与操作系统未实测。独立最终视觉复核为 `ship`，人工查看 14 张代表性最终画面，核对五项源码、两份报告与 157 张截图哈希，见 `verification/finish-review.md`。8317 已安装并重启到 4.5.0，实际返回五项静态资源与验证源码一致，部署后公开页面亦确认配置与回答同时可见。配置与数据库保留，更新未调用模型。实际安装版本与资源哈希见 [本地部署说明](LOCAL_CPA_CN.md)。旧 4.3.0 候选包保持不变。

以下保留 4.4.0 当时的实现与验收记录，仅供历史比较。其中“本轮”、已安装版本、截图数量和通过结论均限定于 4.4.0，不是 4.5.0 的验收结果；其分标签页布局已被本次直接反馈替换。

## UI 4.4.0 历史记录

日期：2026-11-15（Asia/Shanghai）。插件后端版本仍为 0.3.1，UI 为 4.4.0。用户选择的优先级是“配置与主要操作一屏可见”，主要使用场景为 CPA 1280×720 桌面窗口及其真实内嵌宽度。

### 内容与排版

- 保留 CPA 的颜色、字段、按钮、下划线导航、卡片与状态语言。去掉可见的重复页面大标题、介绍及“测试配置”卡片标题；页面 h1 仍供辅助技术识别。
- 智商测试改为“测试配置 / 本次回答 / 测试记录”三个实际工作面，切换时表单保持挂载。开始或查看记录进入回答，返回配置保留草稿；已执行条件继续单独冻结展示。
- 凭证与题目并排，题面占左侧主要宽度，模型与执行选项在右侧。思考强度与回答数量并排，说明缩短；没有删掉参数、限制信息或原文。
- 桌面宽度至少 801px、可用高度至少 600px 时，工作台占用剩余视口。题面在 textarea 内滚动，高级选项在右侧局部滚动；开始按钮位于滚动区域外。
- 回答与历史使用局部阅读区域，任务操作在阅读区域顶部保留。复杂规则和全局预算采用可滚动正文，保存与取消位于正文之外。
- 质量运维将暂停归属和凭证限制并列，统计放在下方；规则、审计使用局部滚动。窄屏和缩放后空间不足时恢复自然页面流，不强制把所有内容缩进一屏。
- 常规文字和触摸目标保持可读。卡片改为 16px 内边距，组内使用 4/8/12px，组间使用 16px；这是响应用户密度目标的明确宿主尺度适配。

### 行为边界

没有修改模型调用、鉴权、调度或质量暂停语义。手动测试仍为单模型、1–8 份独立回答，不自动评分、不暂停凭证。暂停后禁止复测；人工解除只释放匹配归属，规则保持停止。管理密钥仍仅在内存，主题跟随仅读取父页公开主题属性。

无限长题目、回答、记录和规则不能同时完整放进固定屏幕；本轮以桌面配置和主操作无需整页滚动为验收点，长内容保留可访问的局部滚动。手机、200% 缩放和很矮的窗口允许自然页面滚动。

证据目录为 `artifacts/compact-4.4.0/`。基线从不可变的 4.3.0 候选包提取，绑定五项源码哈希；没有把正在修改中的文件当作基线。`baseline/paired/` 与最终截图使用相同 fake 数据。中间失败尝试保留在 preview 目录，最终验证以 `verification/` 中实际通过且绑定当前源码的记录为准。

布局 detector 的五项提示保留在 `verification/layout-detector.json`：两个表格 wrapper 的文字内距由单元格承担，两个原生 dialog 底部由 safe-area/max 表达式及实际测量确认，一项规则处置范围提示承担业务说明。机械提示不代表无障碍认证，也不代替渲染复核。

最终执行并通过：UI 构建与题目逻辑、插件独立 module 测试/race/vet、原生动态库构建与生命周期、原生题目 API 8 项、原生浏览器 13 项、假 API UI 浏览器 57 项、实际宿主外壳 15 项。11 份命令记录均绑定当前输入及声明输出，页面源码、静态资源和动态库实际返回资源一致。宿主 Go 未修改，因此本轮未重复其此前的全量测试。
