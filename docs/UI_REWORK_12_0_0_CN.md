# UI 12.0：账号、测试与质量观察工作台

2026-11-18。适用版本：插件 **0.18.0**，UI **12.0.0**，内嵌 Go/Sobek **2.1.3**，宿主 **CPA 8.0.76**。此版本只做了隔离验证，没有安装到 8317。当时 8317 使用 0.17.3 / UI 11.18.0；随后直接升级到 [0.18.1 / UI 12.1.0](UI_REWORK_12_1_0_CN.md)。

## 从现有功能到新布局

| 使用场景 | 11.18 的具体问题 | 12.0 的处理 |
| --- | --- | --- |
| 进入工作区 | 同一方向上连续出现页标题、一级导航、二级导航和工具栏；独立页和 CPA 内嵌页几乎相同 | 独立宽屏用固定宽度侧栏；同一组导航在 CPA 内嵌页和窄屏变为横栏。默认仍是账号管理，已有 `#manual`、`#operations` 深链接保留 |
| 判断哪些账号需要处理 | 四个计数挤在紧凑筛选器里；身份、CPA 健康与最近操作容易被读成同一状态 | 四个计数直接筛选目录。账号身份及套餐、CPA 已记录的状态、最近任务结果分列。最近登录失败不等于凭证一定失效，未知套餐不等于 Free |
| 对一个账号执行操作 | 六个按钮逐行重复，重置和删除与日志同样醒目 | 登录、资料、日志留在行上；更多菜单分为查看与管理、账号安全。重置 2FA、退出设备和删除复用原确认流程；关闭弹窗回到同一行。移动端菜单跟随行定位，行滚出视口才收起 |
| 核对任务或设置 | 任务列表和详情裹在同一个大面板里；设置中每个分组又形成一张卡 | 历史独立于结果阅读区，结果、已确认步骤、异常与日志按阅读顺序展示。网络、定时巡检、套餐排除共享一个设置表单，只保留一次显式保存 |
| 配置测试、对比回答 | 手机上的历史记录位于长表单下方；为了回看记录需要反复滚动 | 桌面并排放执行条件、题面和回答；窄屏可直接切换「测试设置 / 本次回答 / 测试记录」。同一张表单不卸载，查看历史、展开阅读或改变视口不会丢掉草稿 |
| 解读质量结果 | 历史暂停数量夹在质量指标中；难以判断低覆盖和明确答错的区别 | 同一行列出通过率、覆盖率、结论未知和已知用量。正确数和可判定数、可判定数和计划数分别显示。暂停归属数量回到历史记录标题，不作为质量指标 |

保留的功能包括：批量导入、资料与代理编辑、账号级日志、任务搜索和报告导出、巡检与上传排除；按凭证和模型测试、思考强度、1–8 份回答、历史、下载及隔离 HTML 预览；观察概览、检测规则、审计、全局预算与调度。没有新增自动登录、模型调用、质量暂停或释放接口。

## 视觉与状态约定

- **信息层级**：全局导航与局部标签分开。森林绿用于导航、选中态与主要操作；通过、关注、失败和信息各有语义色，每个结果仍有文字。套餐沿用原配色。统计数字使用等宽字，正文使用系统中文字体，不请求外部字体或图标。
- **场景切换**：独立视口达到 1200px 使用 192px 侧栏。嵌入时不再绘制第二套侧栏，右侧给 CPA 悬浮工具留出空间。低于 960px 测试工作区分屏；不超过 800px 账号表改为纵向记录，不靠横向滚动查找操作。浅色、纯白、深色遵守现有宿主主题契约。
- **数据语义**：未读取用 `—`，成功取得的零才是 `0`。读取失败保留旧列表、提示重试并限制写入。通过率的分母是可判定样本，覆盖率的分母是计划样本；网络错误、限流与未知结论不能当作质量失败。历史归属不随界面切换清除。
- **安全与可访问性**：危险操作不设一键快捷入口。已有身份校验、任务修订号、禁用条件、未确认结果隔离不变。账号页保留键盘方向键切标签与菜单、Escape 关闭与焦点归还；跳到工作区不会改写当前路由。模型生成的 HTML 继续使用无权限沙箱。
- **交付方式**：沿用 Go embed 的六份静态资源和官方管理通道，无新的前端构建框架、远程资源、数据库迁移或运行时升级。
