# 账号列表内登录与资料弹窗（UI 8.3.0）

参考 toSub2-go-port 的账号资料弹窗及登录后留在列表的交互，移除账号列表被整页表单替换和登录后自动切换任务页的行为。参考源码只读。

- 点击行内 2FA 登录直接提交已保存账号，未绑定时默认创建新凭证，已绑定时由宿主使用原绑定目标。提交状态与最新进度显示在原行。
- 不自动跳转任务页；点击账号行的查看任务或核对授权才进入任务详情。候选凭证仍必须手工核对、显式确认保存。
- 账号资料改为原生弹窗：完整邮箱、密码、2FA，备注及自动授权设置。需要更新登录资料时显式勾选。未绑定账号保留折叠的已有凭证目标选项。
- 读取失败在弹窗内提示并重试，关闭后清空资料并归还行按钮焦点。搜索、筛选、页码和滚动位置保留。保存、删除、登录提交中禁止重复操作和误关；失去鉴权或离开功能仍清空。

不修改明文持久化、自动巡检许可、身份核对或质量暂停语义。验证使用本地合成数据，证据在 `artifacts/account-actions-8.3.0/`；安装核验不触发真实登录或模型调用。
