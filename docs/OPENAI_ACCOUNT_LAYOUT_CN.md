# OpenAI 账号列表与导入弹窗（UI 8.2.0）

本次参考 `/Users/ceng/Downloads/toSub2-go-port/web/src/main.jsx` 的账号列表工具栏与批量导入弹窗，保留当前 CPA 三种主题、四个子页及业务流程。参考项目仅用于阅读，没有修改。

## 页面结构

- 账号列表统一为一个工作区：标题与摘要、巡检和导入按钮、带实际数量的筛选、搜索、四列表格及分页。
- 邮箱是每行主信息，备注与完整 CPA 凭证标识放在下方；状态、活动、操作各有固定位置。
- 桌面表头固定，列表局部滚动；手机转换为带标签的账号信息块，完整值换行，避免宽表横向滚动。
- 导入打开原生弹窗，格式说明在输入框上方，实时统计非空行，一次最多 100 个账号。错误显示在弹窗内；底部保留取消和导入操作。

## 交互与持久化

打开导入保留列表搜索、筛选、页码和滚动位置。取消、关闭或 Escape 清空草稿并把焦点返回原入口。提交期间防止重复请求和误关；离开标签页或失去管理鉴权仍会关闭并清空。解析错误保留输入供修正；请求发出后清空输入，服务端失败在弹窗中提示。导入只保存资料，不创建登录任务。

账号、密码、2FA 和密钥的持久化继续使用当前明文方案，详见 [持久化说明](PERSISTENCE_CN.md)。此轮没有存储格式变更、加密或数据迁移。
