# 账号管理工具栏优化

版本：插件 0.29.2 / UI 13.6.2 / Runtime 2.2.1。

## 按钮顺序与层级

原有工具栏内按「导入账号 → 转换凭证 → 巡检全部｜历史记录 → 全局设置」排列，不新增账号数量标题行。

| 入口 | 视觉层级 | 功能 |
| --- | --- | --- |
| 导入账号 | 主题色主按钮 | 打开账号导入弹窗 |
| 转换凭证 | 轻描边 | 打开 sub2api 凭证转换弹窗 |
| 巡检全部 | 轻描边 | 保留现有全部账号巡检操作 |
| 历史记录 | 图标与文字 | 打开历史弹窗，保留数量徽标 |
| 全局设置 | 图标与文字 | 打开全局设置，保留未保存提示 |

前三项与后两项使用语义分组，桌面以细竖线分隔。导入使用既有主题强调色，转换与巡检使用表面色和细边框，历史与设置降低视觉权重。图标统一为 14px 细线，桌面高度 36px、字号 12px、字重 500；悬停、按下及键盘聚焦状态保持清晰。

手机上查询控件一行，账号操作三枚一行，历史和设置两枚一行；按钮高度 40px，保留完整名称。主题色继续来自插件的浅色、纯白和深色变量。

按钮 ID 与绑定不变。账号行操作按钮、资料、历史、设置弹窗和全部业务逻辑不变。

## 验证与部署

- 既有工作区 111 项布局、三套主题及 320px 窄屏检查通过；账号弹窗的焦点、草稿、保存与错误行为通过合成数据验证。
- 原生构建的 Go 检查通过；隔离 CPA 插件加载与重启通过。
- CPA 内嵌候选与安装后页面均校验六份静态资源，业务请求使用合成数据，禁止实际写入。
- 本机 8317 从 0.29.1 / UI 13.6.1 更新，升级前完成停服备份；原有两账号、两条历史任务、一条规则及设置日志保留，宿主镜像、配置和凭证文件保持一致。
