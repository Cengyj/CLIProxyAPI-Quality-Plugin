# 页面使用与前端验证

本文件描述 2026-11-14 重构后的 UI 4.0.0。Model Quality 仍是独立原生插件，页面入口为 `/v0/resource/plugins/model-quality/index.html`。公共入口只提供 HTML、JavaScript 和 CSS 静态资源；数据与操作使用鉴权 v8 管理接口。前端保留原生 HTML、CSS、JavaScript ES Modules，通过 `plugin/ui/embed.go` 的 `ui.Files` 嵌入共享库，没有前端框架、外部字体、CDN 或分析服务。

## 信息架构与操作路径

顶部主导航只有“手动评测”和“质量运维”。连接状态与主题切换在页头，刷新和数据更新时间在工作区上方。未连接时显示连接入口及不调用模型的说明。新版移除了常驻侧栏、导航抽屉和配置/结果并置的旧结构。

| 工作区 | 分区 | 主要任务 |
| --- | --- | --- |
| 手动评测 | 配置评测 | 确定目标、模型、题目与执行条件，再显式提交 |
| 手动评测 | 当前任务 | 观察进度，选择最多两个模型比较回答，审阅证据与人工评审 |
| 手动评测 | 任务历史 | 分页查找记录，打开冻结条件、回答及评审 |
| 质量运维 | 需要关注 | 先查看暂停归属及待处理动作，再核对凭证限制和统计口径 |
| 质量运维 | 检测规则 | 查看规则状态、两层许可、调度与连续失败证据，编辑或显式执行 |
| 质量运维 | 审计记录 | 核对持久化操作审计和近期规则运行 |

“配置评测”的桌面首屏将“目标与模型”“题目与标准”并列，执行参数在下一层，预设和高级参数按需展开。开始执行后切换到“当前任务”，配置表单不再占据结果阅读空间；原配置仍可从分区导航返回。“新建评测”返回配置区，不会隐式执行或取消后台任务。

## 管理连接与请求状态

打开“管理连接”，输入 CPA 管理密钥。所有数据请求使用同源 `/v8/management/plugins/model-quality/` 前缀和 `Authorization: Bearer`。密钥只存在页面内存，不写浏览器存储、URL、HTML 或 JSON 导出；刷新页面、关闭页面或断开连接后需要重新输入。主题选择也仅在当前页面内存保存。

打开页面、连接、刷新、保存配置、载入或保存预设以及保存规则均不调用模型。任务在后台运行，关闭页面不取消任务；需要停止时必须使用明确的取消操作。

断连和 401 会撤销在途管理查询，清除密钥、凭证、历史、回答和暂停动作等页面数据，旧响应不能重填新会话。不同任务详情按最后一次选择生效。轮询失败采用有上限的退避查询，只重新读取进度，不重新提交模型请求。重复提交由操作锁拦截，执行入口按连接、凭证状态和操作中的条件禁用。读取失败会显示数据未更新；凭证状态未确认时禁用新执行。刷新不会覆盖尚未保存的自定义题面。

## 配置与执行手动评测

1. 选择目标凭证及检测模型。凭证显示脱敏 `auth_id`、`auth_index`、provider、类型与可用动作；模型可从按钮选择或按行输入。模型提示只展示宿主提供的推理能力，未知能力保持未知。
2. 选择带版本的内置逻辑题、随机题、SVG 题或自定义题。内置题面不可修改后继续使用原答案；自定义题面与参考标准一起冻结。参考标准不发送给被测模型。
3. 设置每模型 1–8 个样本和输出上限。推理与判题设置收在展开区，保留 Temperature、推理强度及确定性、人工、独立模型判题。独立判题必须使用不同凭证，另计预算；判题失败不是回答错误。
4. 随机题可选择另一凭证作为同批通过对照。自动判定需要同题、同模型映射、同有效条件的有效通过对照，对照也计入调用预算。手动评测本身从不自动暂停或解除凭证。
5. 查看执行计划，点击“开始评测”。任务异步入队后打开当前任务；进度显示已结束样本数与计划样本数。执行完成、回答正确和暂停动作分别记录，不能互相替代。

目标、对照或判题凭证只要被质量暂停，相关新评测、重跑和规则执行都被阻止。不存在暂停中复测、绕过权限或自动恢复入口，服务端也会拒绝此类请求。

“使用或保存预设”提供载入、保存当前配置及删除预设。这些操作不创建检测规则，也不执行模型。预设中的凭证当前不可发现时明确报错，不自动换成其他目标。

## 比较回答与证据审阅

“当前任务”按模型分列组织样本，每个样本保留模型归属、从 1 开始的样本编号、执行状态、质量结论和可比较性。通过“查看模型”“对比模型”选择最多两个模型；可以选择“不对比”，也可按样本编号过滤。桌面比较列按对应样本对齐，手机改为纵向排列，保留同一组筛选入口。尚未取得的计划样本保留位置；终止后缺失的样本明确显示证据不足，不能补成完整失败证据。

长回答以转义后的原文显示，可在受限高度内滚动，也可“展开完整回答”。样本操作保留复制、HTML/SVG 安全预览、条件详情和人工评审。人工评审收在样本展开区，任务结束后可保存结论与备注；评审单独留存，不触发自动暂停或解除。运行中的任务可以取消；结束后只有当前凭证依赖满足条件时才允许同配置重跑。脱敏导出仍为 JSON。

“本轮冻结条件”优先展示目标、模型、题目版本、采样、输出上限、推理参数和判题方式，再展开题面/参考标准、身份及配置版本。样本的“条件详情”展示请求模型、宿主解析模型、固定凭证、执行路径、最终载荷证据、条件是否变化、耗时及用量。原始 JSON 保留在深入排查入口，不承担主要阅读路径。

缺失的 TTFT、usage、证据字段和身份信息显示未知，缺失 usage 不当作零成本。`response_model` 仅是上游返回标记，不构成模型身份认证。网络、鉴权、限流、截断、拒答、取消、判题失败和 unknown 均不等同于明确答错。

## 质量运维与规则编辑

“需要关注”先展示暂停归属、关联凭证、动作版本和可采取的动作。凭证限制分别列出人工禁用、质量暂停、有效可用状态与原因。质量暂停覆盖**整个凭证所有模型的新业务执行**；宿主保存权威状态，插件卸载后仍然生效，列表缺项不表示已有暂停已解除。

质量通过率与覆盖率同时提供统计口径：通过率为正确样本 / 可判定样本，覆盖率为完整可判定样本 / 计划样本。已知用量和未知 usage 分开显示。统计位于待处理事项之后，不再以指标卡片作为运维首屏主角。

“检测规则”显示目标模型、规则状态、全局与规则各自的调度/自动暂停许可、下一次计划、失败门槛与阻断原因。“全部失败”仅指所选检测模型，不代表测试过凭证所有模型。只有完整、可比较、明确答错的有效轮次才推进连续失败计数；未知、缺样、条件变化或混合结果打断连续证据。

规则编辑是工作区内页面，按“检测对象与题目”“处置与调度”“推理与判题设置”组织；全局开关与预算也使用页内编辑。它们不再占用长弹窗。规则保留固定间隔、五段 Cron、时区、样本数、输出上限、推理与判题、失败门槛及保留期。默认只观察，定时检测和自动暂停须由全局与规则两层分别许可。保存不会立即执行。

“暂停检测规则”只停止后续检测，不解除凭证暂停。凭证被质量暂停后，使用它作为目标、对照或判题的所有相关规则与任务都停止，规则显示“等待人工解除”；立即执行、恢复检测和重跑均不可用。编辑不能绕过暂停状态。

全局预算可调整调用、token、响应字节、模型、样本及存储上限。worker、队列和数据目录由安装配置控制，页面不热改这些字段；每凭证并发固定为 1。本版没有分组、按模型隔离、通用 IQ 分数、自动恢复或复测间隔。

## 人工解除与结果核对

解除使用需要专注确认的原生对话框。先从暂停归属打开预览，读取成功前禁用确认；预览以可读字段展示影响凭证、暂停 owner、关联规则、动作标识、动作版本、凭证身份版本、解除范围和已知剩余限制，原始预览 JSON 可展开。

“确认解除，保持检测停止”只释放身份、归属与动作版本匹配的暂停。它不保证凭证恢复业务可用：人工禁用、原生冷却及其他归属限制继续生效。所有相关检测规则仍停止，旧失败计数清零，恢复检测须另行显式操作。

- **版本或归属冲突（409）：** 当前预览失效，禁止重复确认，提示刷新并核对当前动作版本后重新预览。
- **网络或服务错误导致结果不确定：** 明确显示“解除结果尚未确认”，不把错误响应解释为宿主必然未解除；提示不要重复提交，提供“刷新并核对状态”。
- **宿主确认后：** 重新读取动作与目标。原归属不在活动列表时，展示剩余限制和规则继续停止；仍有人工禁用等限制时明确保留，不宣称整体恢复可用。

## HTML / SVG 隔离

原始回答始终转义。安全预览生成独立 `srcdoc`，iframe 使用空 `sandbox`、`inert` 和 `tabindex=-1`，不授权脚本、同源、弹窗、表单或顶层导航。CSP 在内容前生效，`default-src 'none'`，拒绝网络、脚本、子 frame、外部字体和表单，仅允许内联样式和 data 图片。预处理移除脚本、iframe、object、base、meta、link、form、链接/地图元素，删除事件、资源和导航属性，并过滤能修改资源与导航属性的 SVG 动画。

预览不提供鼠标/键盘交互或 JavaScript 动画；CSS/SVG 的纯视觉动画可以展示。预览最多接受 1 MiB 原文，超过上限拒绝；后端另有响应上限。

## 可复现构建、检查与截图

静态构建检查 JavaScript，并复制发布文件及 SHA-256 清单到 `artifacts/ui/`：

```sh
sh scripts/build_ui.sh
# Node 不在 PATH 时：
NODE_BIN=/path/to/node sh scripts/build_ui.sh
```

浏览器回归使用 Playwright 和本机 Chrome。fake 管理 API 验证不调用真实模型账号：

```sh

CHROME_PATH=/path/to/chrome \
node scripts/verify_ui.cjs
```

原生验证需要先重建嵌入共享库；`scripts/build.sh` 同时构建独立插件和工作区宿主。`scripts/verify_native_ui.cjs` 自行启动隔离 demo，实际使用带补丁宿主、共享库、管理鉴权和后台 engine，模型服务替换为本机 fake upstream：

```sh

PLAYWRIGHT_MODULE=/path/to/node_modules/playwright \
CHROME_PATH=/path/to/chrome \
node scripts/verify_native_ui.cjs
```

fake API 回归保留业务和安全断言，并覆盖新的分区导航、双模型与样本筛选、长回答、冻结条件、页内编辑、主题、响应式布局、解除冲突和结果不确定。既有覆盖包括静态壳/连接/保存无模型调用、内存密钥、评审、重跑、取消、目标/对照/判题暂停阻断、规则停止、人工 CAS 解除、剩余人工禁用、HTML/SVG 隔离、重复提交、迟到响应、轮询恢复、断连撤销及 401 清理。轮询时序使用可控时钟，延迟响应使用 Promise 屏障。
