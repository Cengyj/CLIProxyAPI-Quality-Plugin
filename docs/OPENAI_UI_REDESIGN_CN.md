# OpenAI 登录与账号管理 UI 7.0.0

本次将 OpenAI 登录工作区重新组织为账号目录、操作侧栏和登录任务详情，插件版本为 0.6.0。整体延续 CPA 的浅色、纯白、深色三种主题，智商测试和质量运维保持原有流程。

## 页面与操作

- 顶部使用紧凑标题与「账号／临时登录／登录任务」切换，去除整页重复的大卡片容器。
- 账号目录按账号、CPA 状态、最近活动、操作四列展示；支持邮箱、备注、CPA 凭证搜索，以及全部、待处理、已绑定筛选。每页最多 20 个账号。
- 桌面右侧 312px 操作栏默认展示巡检设置，导入账号、账号资料、登录目标选择在同一区域切换。账号列表与操作栏独立滚动，保存和开始动作保持可见。
- 临时登录采用宽表单加简要流程说明；登录任务采用列表与详情并排布局，候选凭证确认按钮保留在详情底部。
- 明确打开任务时，列表自动显示所选行；选中边框与悬停效果不同。后台刷新不会把用户手动滚动的位置拉回。
- 窄屏使用自然页面滚动，编辑或打开巡检设置时，操作面板排在账号列表之前。提供直接进入巡检设置的入口。

## 完整信息展示

按本次要求，账号邮箱、CPA 凭证标识、候选账号／工作区与用户 ID 完整显示，不使用脱敏字段。账号资料通过鉴权详情接口读取，密码和 TOTP 长期密钥使用可读文本框。初始只读，勾选「同时更新登录资料」后可替换密码与 TOTP 密钥。

新增接口：`GET /v8/management/credential-logins/accounts/detail?id=...`，返回账号记录和完整登录资料，带 `no-store`，不触发登录。账号列表、任务、目标与候选接口补齐完整身份字段；旧脱敏字段仅为兼容保留，当前页面不采用。

登录资料仍加密保存在宿主，页面不写入浏览器存储或日志。关闭编辑、切换页面、断开鉴权后清空已加载资料。异步请求以账号、页面与请求序号校验，旧响应不能填回已经关闭或切换的账号。

## 交互修正

取消删除不会清空当前只读邮箱；保存或资料读取失败保留可识别的账号身份并提示重试。切换登录任务会立即撤下旧任务的提交、取消等动作，避免新任务读取期间操作到旧任务。

巡检、全局自动重新授权、每账号自动授权仍分别配置并显式保存。首次授权依旧核对候选后确认。质量暂停、人工禁用和原生冷却保持独立，不因布局或登录授权改变。
