# 账号管理筛选与弹窗优化

版本：插件 0.28.5 / UI 13.5.1 / Go＋Sobek 2.2.1。

## 入口与排版

账号列表成为账号管理的唯一主视图。状态筛选改为原生下拉组合框，保留全部、待处理、已绑定、进行中四种范围及实时数量，继续与邮箱、备注、凭证搜索组合使用。筛选后重置分页，清除筛选恢复全部账号。

原登录任务、登录设置页签改为「历史记录」「全局设置」两个图标按钮，相关标题、关闭按钮、更多菜单及帮助提示同步更新。UI 13.5.1 移除新增的账号数量标题栏，将两个按钮并入搜索、转换凭证、巡检和导入所在的操作栏；桌面同排，窄屏自动换行。账号数量仍可在状态下拉框中查看。

- 历史记录：包含登录、授权、重置 2FA 和退出设备的既有任务记录。桌面左侧为搜索、状态下拉框与记录列表，右侧查看详情和日志；窄屏上下排布。刷新、导出、关闭固定在底栏。
- 全局设置：按登录网络、定时巡检、CPA 上传排除套餐分区。使用原有配置字段、代理顺序、启停限制与套餐配色；关闭、保存固定在底栏。
- 两个弹窗沿用产品现有主题，统一细边框、轻量字号、间距及按钮尺寸。小屏内嵌 CPA 时避开宿主浮动工具栏。

## 交互

使用原生 dialog 保持焦点约束。Esc 和关闭按钮返回原入口；账号更多菜单可直接打开该账号的历史记录。搜索词与账号列表筛选不会因弹窗开关而清空。

全局设置关闭后保留浏览器内的未保存草稿，入口显示“未保存”；再次打开继续编辑。保存期间禁用关闭，确认保存后清除草稿标记。错误展示在弹窗内，版本冲突沿用原有重新读取和核对流程。切换主工作区时关闭弹窗，断开管理连接清空草稿。

本轮不改变接口、定时调度、凭证处理或安全操作语义。打开、关闭、搜索和筛选均不触发账号操作。

## 验证

验证包含三种主题、六种屏宽的 36 个弹窗布局，检查固定底栏、视口适配和横向溢出；另检查账号筛选、历史入口、空结果、草稿保留、焦点返回、保存中关闭保护、成功保存、错误与冲突反馈。配置写入测试只作用于一次性内存测试服务。

CPA 真实管理壳分别验证候选与已安装页面，业务数据转向合成测试服务并禁止写入。原生包经过隔离构建、加载和重启验证。UI 13.5.1 证据位于 `artifacts/account-toolbar-0.28.5/`；前版完整假上游策略验证保存在 `artifacts/account-dialogs-0.28.4/`，本次已核对后台业务源码未变。

本机 8317 已从插件 0.28.4 / UI 13.5.0 升级。停服备份后只替换插件库；2 个账号、2 条历史任务、1 条规则、设置及日志均保留，CPA 镜像、配置和凭证文件未变。已安装的六份 UI 资源与安装包校验值一致，真实管理写入为 0。
