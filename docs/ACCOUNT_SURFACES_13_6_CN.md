# 历史记录、全局设置与账号资料重构

版本：插件 0.29.0 / UI 13.6.0 / Runtime 2.2.1。

## 内容核查与设计方向

历史记录包含登录、授权、重置 2FA、退出设备、自动登录以及旧任务。列表搜索和状态过滤、诊断建议、逐条日志、复制和导出仍需完整保留。此前搜索与状态分散在侧栏，列表与详情重复使用卡片，详情以大状态图标占据顶部。

全局设置包含默认代理、巡检开关与周期、自动重登全局许可、CPA 上传套餐排除。原两列卡片切断阅读顺序，说明比控制项更突出。本次按“登录网络 → 定时巡检 → 上传策略”连续排列。

账号资料包含固定邮箱、可选更新的密码及 2FA、资料复制、备注、独立代理及实际出口、账号自动登录许可、CPA 绑定和指定已有凭证登录。安全待核对信息需要优先展示；不得因为视觉调整隐藏或解除原有禁用条件。

三处统一沿用插件主题变量、细边线、16px 弹窗标题、11–13px 信息层级、36px 输入控件和固定底部操作栏。主账号页维持 UI 13.5.1 的单行工具栏，不恢复已移除的账号数量标题区。

## 历史记录

- 顶部统一查询栏：账号 / 操作 / 错误搜索、记录状态和匹配数量。
- 桌面使用 288px 记录列表与可独立滚动的详情；列表减少边框，选中项通过细边线与侧边标记区分。
- 详情先展示操作类型、结果状态、账号和时间；错误以左侧细线和轻背景突出，继续提供停止步骤和处理建议。
- 执行日志取消外层套框，保留事件数量、异常筛选、搜索、复制诊断、导出 JSON、跟随最新、日志保留提示和诊断字段。
- 手机端将记录列表改为横向浏览，选择记录时将当前项滚入可视区域，详情在下方。标题、查询栏及底部按钮固定。

## 全局设置

- 连续三分区：桌面左侧标题与说明、右侧控件，手机改为纵向排列。
- 代理输入先展示；格式、容器地址、优先级和存储说明放在“代理格式与使用顺序”中。
- 巡检开关、间隔、异常自动登录按依赖顺序排列，数值与单位同一控件，保留原 5–1440 分钟限制。
- 上传套餐明确“排除以下套餐 / 未勾选即允许”，继续使用原有套餐颜色。适用范围直接展示，详细处理规则可展开查看。
- 草稿、保存中关闭保护、成功反馈、错误和版本冲突行为保留。只有点击保存才写入配置。

## 账号资料

- 桌面分为登录资料与账号配置两栏，中间细线分隔；手机改为连续纵向区域。
- 左侧展示邮箱、密码、2FA，复制入口放在分区标题旁。勾选“更新密码与 2FA”后才允许编辑，保持原来的显式更新规则。
- 右侧为备注、登录代理、已保存的实际出口、自动登录许可及 CPA 绑定；未绑定账号仍可展开选择已有凭证作为登录目标。
- 安全待核对区域置于最前，仍使用原业务条件禁用修改、删除和复制。新密钥核对与完成本地保存入口完整保留。
- 标题与删除 / 关闭 / 保存固定；内容独立滚动。关闭后清空密码、2FA 和代理资料，焦点返回原账号按钮。
- 读取失败可重新读取；保存失败后保留原来的重新读取确认要求，不自动重试写入。

## 验证与部署

离线内存数据覆盖三种主题、六种屏宽的历史 / 设置弹窗，以及五种屏宽和短屏的 16 项账号资料布局。检查筛选、日志、草稿、保存中关闭限制、设置成功 / 错误 / 冲突、资料读取失败 / 重试、资料保存错误、凭证字段不随普通配置更新提交、安全待核对禁用与关闭后清空资料。

CPA 管理壳内分别验证候选和已安装 UI，所有业务请求转向合成服务；仅在合成服务执行配置及资料保存。原生插件构建执行 Go 检查，隔离容器验证加载与重启；宿主源码保持不变。最终结果与部署备份以 `artifacts/account-surfaces-0.29.0/verification-summary.json` 为准。


本机已从 0.28.5 / UI 13.5.1 升级，停服备份完成。2 个账号、2 条历史任务、1 条规则及设置、日志保留；CPA 镜像、配置和凭证文件未变。实际服务的六份资源与安装包一致。
