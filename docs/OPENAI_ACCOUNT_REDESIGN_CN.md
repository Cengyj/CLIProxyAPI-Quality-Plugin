# OpenAI 账号目录重构：UI 8.5.0

本轮对应插件 0.9.1 / UI 8.5.0，参考 `/Users/ceng/Downloads/toSub2-go-port/docs/pure-go-runtime/ui/account-table-compact-20261104-wide.jpg` 的账号控制台排版。只更新插件页面，登录运行包、代理能力与明文持久化方式沿用上一版。

## 新布局

- 顶部四个紧凑入口：全部账号、待处理、已绑定 CPA、登录中。前三个筛选列表，登录中打开任务页，不提交登录。
- 搜索、代理、巡检和导入集中到一条工具栏，移除重复筛选条和说明。
- 表格分为账号、CPA 状态、最近授权、登录出口、操作五列。CPA 的认证状态与上次登录结果分别显示；未知状态保持中性，已绑定不代表可用。
- 白底表格内缩16px，邮箱、凭证ID与代理地址完整换行。登录和资料操作横向并排；历史失败列表仅显示简短说明，详细步骤仍在任务页。
- 单账号时面板自然收拢，多账号时列表独立滚动、分页保持可见。低矮桌面使用64px概览，1554×605可完整看到第一行与第二行操作。
- 手机概览两列排列，账号信息按标签分组；工具栏和行操作高度至少44px。导入、资料仍为原位弹窗，点击2FA登录仍留在列表。

## UI 8.5.1：去除臃肿结构

用户反馈8.5.0统计卡与嵌套表格仍显臃肿。本版以一行紧凑筛选替换四张大统计卡，移除重复标题、账号总数说明以及外层卡片；搜索与代理、巡检、导入直接排在筛选右侧，下方紧接五列表格。普通单账号行高约84px；完整代理、凭证ID和巡检时间允许自然换行。

1554×605相同离线单账号场景的内容底部从438px提前到321px，约减少117px。390×844手机的首行操作从y≈883提前到y≈675，44px按钮可在首屏看到。状态、筛选、直接登录、原位资料与导入弹窗、代理和持久化行为保留。证据目录：`artifacts/account-compact-8.5.1/`。

## UI 8.6.0：改为账号行

8.5.1仍被用户指出视觉没有实质变化，本轮改掉五列表格结构，使用语义化账号列表。完整邮箱与CPA状态相邻，最近授权和任务入口位于同一信息组下方；代理及登录、资料操作放在右侧，移除表头和独立元数据列。目录宽度限制1120px，普通行不展示多行巡检、凭证ID和历史原因。

“详情”在原账号行下展开CPA凭证、巡检时间、自动授权及最近授权的完整原因。通过原生button的aria-expanded/aria-controls与内容hidden状态控制；数据刷新时保留展开状态和键盘焦点，展开不调用写接口。账号登录结果与代理错误仍直接显示；密码与2FA资料继续在资料弹窗中完整查看。

本轮证据目录为`artifacts/account-rows-8.6.0/`。账号检查新增只读详情、键盘Enter、刷新后的展开/关闭及焦点保持检查。桌面、手机、三主题截图均使用离线假账号；不启动真实OpenAI登录或模型调用。

用户明确指出没有要求缩减列，8.6.0的合并账号行与详情折叠因此撤回。恢复账号、CPA状态、最近授权、登录出口、操作五列，自动授权、凭证ID、诊断、巡检及授权时间、代理来源直接显示。仅调整列宽、单元格间距与顶行对齐；不通过删除列或隐藏字段简化界面。
