# 账号操作提示卡片移除与 2FA 登录反馈

版本：插件 0.29.3 / UI 13.6.3 / Runtime 2.2.1。

## 界面调整

删除账号管理顶部的整个 `login-notice` 卡片容器及专用样式。登录开始、完成和普通操作不再插入提示横幅；辅助阅读器仍可收到普通完成信息。

2FA 登录入口使用既有主题的轻底色。提交、排队、登录、授权、核验和保存显示简短状态与细环加载图标；当前步骤与结果仍在“最近操作”内展示。运行中的按钮保持文字清晰并禁止重复操作，待确认或待核对状态不使用加载动画。系统要求减少动态效果时关闭旋转。

账号列表的请求错误在工具栏下使用无背景、无边框的简短文字；弹窗错误保留在各自表单内。移除启动提示不影响账号导入、删除、巡检、资料编辑以及错误核对。登录、保存与启用的后台实现和策略保持不变。

## 验证与部署

- 合成账号验证提交防重、原位加载、筛选与行位置保持、登录成功、请求失败及待核对限制；三主题、桌面和手机检查通过。
- 原有 111 项布局、历史/设置/资料交互，以及删除失败、取消和确认流程通过。
- 原生构建运行 Go 测试与 vet，隔离 CPA 加载和重启通过；候选与安装后内嵌页面校验静态资源，业务请求均使用临时合成数据。
- 本机 8317 从 0.29.2 升级前完成停服备份，2 个账号、5 条已有历史任务、1 条规则及日志设置保留，CPA 镜像、配置和凭证文件不变；验证没有发起真实登录或模型调用。
