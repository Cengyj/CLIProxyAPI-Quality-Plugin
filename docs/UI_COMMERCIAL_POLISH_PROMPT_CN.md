## 4. 按宿主组件体系重做基础层

先建立可维护的 token 与组件层，再将两大工作区整体迁移。禁止不断追加覆盖 CSS；移除被替代的规则和无引用结构。

### 颜色与排版

- 按宿主角色建立 page、card、input、floating、hover、border、text、action、focus、status 映射。参考 light 的页面 `#faf9f5`、卡片 `#f0eee8`、浮层 `#fffdf9`；white 与 dark 独立映射，避免普通卡片和浮层混用角色。
- 使用宿主系统字体体系，保留中文回退；无远程字体。页面标题参考插件管理页的 28px/700、说明 14px，卡片标题参考 18px/700；按真实内容适配，不靠缩小关键文字压缩页面。
- 间距以宿主 4/8/16/24/32/48px 为骨架。基础控件圆角参考 8px，卡片/弹窗参考 12px。特殊变体要有明确用途，不能每页一套尺度。
- 保留对比度。宿主 `#8b8680` 白字约 3.61:1，不能直接用于普通小字后宣称合格；可沿暖灰色阶采用更深行动色。当前 `#726d67` 白字约 5.12:1，可作为参考。偏差及原因记录在设计文档中。
- 普通文本以 4.5:1、适用大字和控件边界/状态以 3:1 为验收目标；这不是已获得无障碍认证的声明。实际检查所有主题和关键状态。

### 按钮、字段与选择器

- 对齐宿主 primary、secondary、ghost、danger 与 md/sm 的职责、布局、图标间距和 loading 反馈。主要提交显著，同一区域主次明确；危险确认只用于真正具有后果的动作。
- 字段统一 label、control、hint、error 结构，参考轻边框、8px 圆角和聚焦环。默认边界仍须可辨认。
- 手机输入字号至少 16px、主要触摸目标至少 44px；宿主桌面小尺寸不能机械复用到手机。
- 原生 select 可以经过样式适配保留。长凭证或模型选项需要搜索时才做可访问 combobox，补全键盘、选中、过滤、空结果、关闭和焦点行为，不能只画一个外观相似的下拉框。
- 控件覆盖 default、hover、focus、active、disabled、busy、error；加载时保持按钮宽度，提交失败保留输入，字段错误就近展示并关联描述。

### 卡片、Tabs、开关、表格与状态

- 使用宿主 Card 的标题/操作/正文骨架，参考 24px padding、12px 圆角、轻阴影和边框。按任务组织工作面，避免反复套卡片。
- 导航共用 ProviderTabs 的下划线、选中、hover 与 focus 语言。两大任务与局部分区层级明确，窄屏支持换行或受控横向滚动。
- 布尔配置参考 ToggleSwitch 的 44×24 轨道与 18px 滑块，保留原生 checkbox 的可访问性。需要保存的规则开关仍通过保存生效；“启用规则”“启用定时检测”“允许自动暂停”不能合并。
- 规则、凭证与审计统一表头、行密度、边界、hover、数值对齐和操作栏。手机采用可读行/卡片或局部表格滚动，页面本身不出现横向溢出。
- 状态、提示、空状态、加载、失败统一组件。完成调用、质量正确、规则启用、凭证有效可用分别表达；不能给“已完成”附加未经判定的质量含义。
- 缺失用量显示未知，真实零显示 0；无数据、未连接、未加载、无匹配和加载失败分别说明。

### 弹窗、详情与反馈

- 参考 Modal/Sheet 的头部、内容滚动、底部动作与关闭位置。可继续使用原生 dialog，保留 Esc、焦点约束、关闭返回焦点和背景不可交互。
- 连接、短确认和人工解除使用清楚的弹窗；复杂规则表单优先保留页内空间；确有阅读需要的详情才用抽屉。不要把所有任务塞进同一种浮层。
- 复制反馈贴近操作；保存结果绑定对象；连接失效、状态陈旧和解除结果不确定持续显示在正确位置。完善已有局部反馈与 action dialog，不退回浏览器 prompt/confirm。
- 图标采用宿主线性语言，统一尺寸、线宽和基线。动效参考 150–200ms 常规反馈，尊重 reduced-motion，不让轮询触发整页入场或移动阅读位置。

## 5. 重排两大工作区

### 智商测试

保留“选题并读回答”的连续任务：凭证 → 题目与可编辑题面 → 单模型/思考强度/1–8 份回答 → 显式开始 → 同页结果。输出上限与 Temperature 保持次级展开设置。

桌面采用测试配置工作面，题面占主要宽度，选项占次要宽度；结果是下方独立阅读工作面。组件结构与 CPA 对齐，列宽按实际内容确定。手机按任务顺序排列，开始测试容易找到，查看结果不必反复经过重复说明。

执行后可提供“查看回答”和配置展开/收起入口，保留题面草稿与冻结条件的区别，不丢弃表单或隐藏运行状态。回答区域按数量和内容调整密度，短答案不产生大面积占位，长自然语言与 HTML/SVG 原文各有适合的阅读样式。复制与导出保持原文。

保留本次测试/测试记录、进度、停止、符合条件的同配置再测试、复制、脱敏下载和隔离预览。不重新引入手动页已移除的通用评测配置、多模型输入、预设、对照和 judge 表单；旧记录与旧 API 兼容继续保留。

糖果题答案只绑定准确题面和版本；编辑内置题后明确变为自定义题，不继承答案。手动测试不自动评分、不输出通用 IQ 分数、不触发质量暂停。

### 质量运维

保留需要关注、检测规则、审计记录三个分区。需要关注先呈现需处理的暂停归属、影响凭证和当前限制；统计放在次级位置。无待处理事项时保持简洁。

检测规则使用统一列表/表格与分组表单。目标与题目、判定条件、调度、处置、预算各自清楚；保存、立即执行、暂停/恢复检测规则各有明确动作。长 ID 可查看完整内容，不挤压操作。

人工解除继续展示准确对象、归属、版本、影响与剩余限制。正常、冲突、结果不确定、重新核对分别呈现；不能用绿色成功提示暗示凭证已整体恢复可用。解除后规则继续停止，恢复规则是另一个显式动作。

## 6. 产品与实现边界

- 质量暂停针对整个凭证所有模型的新业务执行；暂停中禁止全部手动/自动测试，以及作为对照或 judge 使用，无绕过或自动恢复。
- 只允许完整、可比较、明确错误的证据推进失败判定；基础设施异常、拒答、取消、截断与 unknown 不算答错。
- 人工禁用、质量暂停、原生冷却与其他归属分别存在；人工解除只释放匹配归属、身份与动作版本，清空旧失败计数并保持依赖规则停止。
- 管理密钥只在插件内存；数据与动作继续走同源鉴权 v8 API。公共 v0 resource GET 仅静态内容。查看、连接、切换主题和保存配置不调用模型。
- 保留迟到响应隔离、401/断连清理、防重提交、取消链路、轮询恢复和草稿保护。轮询不得打断输入、选择、焦点、展开状态或阅读位置。
- 模型内容保持不可信：原文转义，预览保留空 sandbox、inert、严格 CSP 和脚本、网络、表单、导航封锁，不读取宿主页。
- 保留原生 HTML/CSS/ES Modules 与 Go embed；无需为参考 React 组件而迁移框架或引入组件库、运行时 CDN、远程字体。独立实现组件外观与契约；直接复用代码/样式时保留来源与许可证。
- 新模块/资源加入时同步静态路由、embed、构建清单、哈希校验与打包工具，不能依赖发行包未包含的文件。
- 原 CPA 参考目录只读。必要宿主 Go 修改只在工作副本进行，完成其 AGENTS 检查及可复现补丁；纯前端外观调整不扩张为宿主业务重写。
