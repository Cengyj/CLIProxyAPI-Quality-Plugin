# UI 4.8.0 滚动与对齐修正

本轮按用户截图修正智商测试布局，保留凭证与题目在左、模型与思考选项在右的结构，以及现有凭证限制和手动测试语义。

- 题目版本与编辑提示移入独立网格行，开始按钮与编辑框底部对齐；窄屏按正常文档顺序排列。
- 回答区正常状态按内容收紧高度，“展开阅读”才占满剩余空间。工具栏固定在内容区之外，回答和历史各自滚动。
- 移除历史正文重复标题，取消强制100%高度；空记录没有多余滚动，只有超过一页或位于后续页时才显示分页。
- 普通回答宽度限制为80ch，长行更易阅读；代码回答与多份回答比较保留可用宽度。
